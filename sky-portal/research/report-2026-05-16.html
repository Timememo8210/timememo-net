Source: Microsoft Tech Community, Microsoft Learn

💡 实用技巧：Copilot Studio自定义连接器——打通内部系统

Copilot Studio最新支持的自定义连接器功能，让企业可以将自己的REST API直接注册到Copilot工作流中。在Copilot Studio中选择"Actions"→"Add custom connector"，输入API的OpenAPI spec URL即可完成配置。这样Copilot就能直接查询内部CRM、ERP等系统数据，在聊天中回答"上个月华东区销售额是多少"这类问题。配置完成后记得测试端点连通性并设置适当的OAuth认证。

Source: Microsoft Learn, Copilot Studio Docs

Anthropic发布Project Glasswing：联合12家科技巨头守护关键软件安全

Anthropic宣布启动Project Glasswing，联合AWS、Apple、Google、Microsoft、NVIDIA、Cisco、CrowdStrike等12家科技巨头，旨在利用AI能力发现并修复全球最关键软件中的安全漏洞。该项目基于Anthropic未发布的前沿模型Claude Mythos Preview，该模型已发现数千个高严重性漏洞，涵盖所有主流操作系统和浏览器。Anthropic承诺投入最高1亿美元的Mythos Preview使用信用和400万美元直接捐赠给开源安全组织。

Source: Anthropic Official, The Verge

Anthropic与Google/Broadcom签署数GW级TPU算力协议，年化收入破$300亿

Anthropic宣布与Google和Broadcom签署新一代TPU算力协议，预计2027年上线多个GW级算力容量。Anthropic年化收入已突破$300亿，较2025年底的约$90亿增长超3倍。年消费超$100万的企业客户从2月的500+翻倍至1000+，不到两个月翻番。Amazon仍是主要云提供商和训练合作伙伴。Claude是目前唯一同时部署在AWS Bedrock、Google Cloud Vertex AI和Microsoft Azure Foundry三大云平台的前沿AI模型。

Source: Anthropic Official

Anthropic洽谈收购Stainless：SDK工具商估值$3亿+

据The Information报道，Anthropic正在深入谈判收购开发者工具创业公司Stainless，估值至少$3亿。Stainless为OpenAI和Google等公司提供API SDK生成工具。此举显示Anthropic正在加大对开发者生态的投资，进一步巩固其在企业AI市场的地位。同时，Anthropic还与PwC扩大合作，将Claude Code和Cowork推广至PwC全球数十万专业人员，并培训认证3万名员工。
