AI Web HTML

HTML 是 AI 和人之间、人和人之间沟通的最佳桥梁。
这里有晓波关于这个方向的所有思考、研究和产品原型。

Core Insights

晓波的三个核心洞察

洞察 01

HTML 是 AI 之间的沟通桥梁

多 Agent 协作时用 HTML 标注修复进度（红黄蓝）。一个 Agent 修复、另一个检查，不行就再派 sub-agent。迭代10轮仍失败就标注问题换方案。核心目标：一次性修好。

洞察 02

HTML 是三重沟通媒介

AI↔AI：结构化信息密度高，Agent间传递上下文更精准。
AI↔人：图表+交互+颜色编码，人类读起来顺畅。
人↔人：一个链接搞定，有浏览器就能看，比Word/PDF/PPT高效太多。

洞察 03

可编辑 HTML = 下一步

HTML 当前不能快速大量编辑。但 AI 存在后，这个问题可以打破——用户说一句话，AI 自动修改 HTML。AI Web HTML 的核心：人与人之间分享的便利性。

"这个沟通的效率和简单的程度是不可想象的。只需要有浏览器就能看。这就是 AI Web HTML 的核心——人与人之间分享的便利性。" —— 晓波，2026-05-10

墨记 Web — 产品原型演示

每个人一个网页空间，每条内容是AI生成的完整网页。交互式原型可体验。

2026-05-10MVP 原型
Product Plan

最小化产品规划

🎯 产品目标

让任何人通过"说一句话"就能生成一个可分享的、丰富的网页。用 HTML 替代 Markdown/PDF/PPT 成为 AI 时代的信息载体。

Phase 0：概念验证 ✅

已有 Sky Portal 作为活广告。晓波每天用 AI 生成网页内容并分享。核心模式已验证。

✓ 完成

Phase 1：语音/文字 → 网页（MVP核心）

输入：用户说一段话（30秒-3分钟）或打文字
处理：Whisper语音→文字 → Gemini 2.5 Flash结构化处理 → 模板引擎生成HTML
输出：一个可分享的网页链接
技术栈：Next.js + Cloudflare Workers + R2 + D1

🔄 进行中

Phase 2：个人空间 + 时间线

每个人一个主页（username.mojiweb.app），展示所有发布的网页。时间线/瀑布流布局。支持搜索。

📋 规划中

Phase 3：社交互动

评论、分享、关注。AI自动推荐相关内容。从个人工具变成社交平台。

📋 规划中

Phase 4：可编辑 HTML + 协作

收到的网页可以"说一句话"让AI修改。多人协作编辑同一个网页。HTML从只读变成可读写。

📋 远期

Phase 5：AI Agent 间 HTML 通信

多个 AI Agent 用 HTML 协作：红黄蓝标注状态、sub-agent修复链、10轮迭代自动流程。HTML 成为 Agent 间的标准通信协议。

📋 远期
最小化验证方案：先把 Phase 1 做出来——"说一句话 → AI生成网页 → 分享链接"。不需要注册登录，不需要用户系统。一个页面，一个输入框，一个生成按钮，一个分享链接。验证这个核心循环是否成立。
Research

竞品调研结论

🔍 市场空白确认

分析了20+个产品，确认没有竞品做到"每条社交内容 = 一个完整的、AI生成的、可互动的网页"。

最接近的竞品

小红书/抖音（内容形态完全不同）、Memairy（封闭App无社交）、Obsidian Publish（面向知识工作者）、Carrd（只有门面没内容）

时间窗口

1-2年。大厂可能跟进。先发优势 + 社区壁垒是核心防御。
