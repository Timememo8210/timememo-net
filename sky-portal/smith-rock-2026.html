Smith Rock 周末独行攻略

从 Portland 出发，Tesla Model X / Model Y，按“充电必须有余量、Misery Ridge 不硬扛、Bend 只在值得时加”的标准做的一日往返 + 住一晚双方案。

先说结论

这里正式名字是 Smith Rock State Park，不是 National Park。对你来说它更像一个“开车近、视觉强、充电稳”的高质量周末目的地。

方案 A - 周六当天往返

推荐

适合你说的“早上 5-6 点出发、上午完成硬 trail、下午回、周日完整恢复”。核心做 Misery Ridge + River Loop；太热就降级成 Crooked River。

  • Madras 是主充电点，Redmond 是最近备份，Bend 是南侧兜底。
  • Misery Ridge 要在上午做，不要下午晒到最热时才开爬。
  • 不喝酒、不恋战，下午离园，晚上 8:30-9:30 回 Portland。

方案 B - 住 Bend 一晚

想喝酒才值

Bend 离 Smith Rock 约 30-45 分钟，不远。但一个人旅行时，它不是必加项。只有你想在 Bend 坐一坐、喝一杯、不想疲劳夜驾，才值得住一晚。

  • 走完 Misery Ridge 后去 Bend，晚上 Old Mill / Downtown 轻松吃饭。
  • 喝酒就不要当天开回 Portland，直接住 Bend。
  • 第二天只做 Deschutes River Trail / Pilot Butte 这种轻项目。

Tesla 充电策略

可靠性优先，不追求极限续航。车机导航仍然是出发当天最终依据，因为它会看温度、海拔、车速和实时占用。

不用赌

Model X 单段没压力，往返别硬撑

Portland 到 Smith Rock 单程约 140-150 miles。Model X 跑过去没问题，但山区、高速、空调和温度会吃掉余量，所以不要设计成“不充电往返”。

无园内超充

公园附近有两个靠谱节点

Smith Rock 内没有 Supercharger。北侧 Madras 是主节点，南侧 Redmond 离公园最近；两个都是 8 stalls、最高 250 kW、24/7。

低风险

真正风险是排队和低电量进山

出发前 90-100%，到 Madras 低于 40% 就补到 75-85%。回程低于 55-60% 就在 Madras 或 Redmond 再补，不靠 FSD 硬赶夜路。

路线与景点地图

地图标的是“规划用点位”，精确导航请交给 Tesla 车机或 Google Maps。蓝线是公园内建议徒步，橙线是车程骨架。

地图怎么读

距离换算

Portland 到 Smith Rock 约 140-150 miles；Smith Rock 到 Redmond 约 11 miles；Smith Rock 到 Madras 约 21 miles；Smith Rock 到 Bend 约 30-45 分钟。

必玩徒步项目

一个人去，不建议把所有路线都硬塞。Misery Ridge 是最有代表性的硬路线，但暑期要早走、带水、别在最热时段硬上。

Bend 要不要加？

Smith Rock 到 Bend 约 30-45 分钟。对一个人来说，Bend 是“想放松才加”，不是必玩清单。

My verdict

默认当天回；想喝酒才住 Bend

你的旅行习惯更像 Quiet Lake 那种高效率打法：早出发、完成核心 trail、下午撤、周日恢复。Smith Rock 也适合这样。Bend 值得加的唯一强理由，是你走完 Misery Ridge 后想在 Old Mill / Downtown 坐一坐、喝一杯、不要再夜驾。

最适合你：周六当天来回

05:45-06:15 出发，09:00 前后 Madras 补电，10:00 前开始 Misery Ridge + River Loop，下午 3-4 点离园，Madras 再补电，晚上回 Portland。紧凑但不拖泥带水。

想小度假：Smith Rock 后住 Bend

下午从 Smith Rock 开 30-45 分钟到 Bend，先去 Bend Supercharger 或酒店，晚上 Old Mill / Downtown 吃饭喝一杯。第二天只走 Deschutes River Trail Old Mill Reach 或 Pilot Butte，午后回 Portland。

不推荐：硬 trail + Bend 喝酒 + 当晚回

Misery Ridge 晒完以后身体会疲劳。Bend 如果只是“顺便看一下”会让当天变长；如果喝酒，再开 3 小时回 Portland 不值得。

周六一日往返时间表

这个版本保留周日完整休息，并把 Misery Ridge 放在上午。所有时间按 Portland 市区出发估算，住在西边或南边就相应前后调整。

4

Smith Rock Bivy

只适合你想帐篷露营。First-come first-served，无预订；禁止睡车、RV、明火。这次一个人不建议优先选。

Bivy 规则

自动驾驶与安全边界

把 FSD / Autopilot 当作减负工具，不当作“自己开过去”。这条路线有山路、施工、两车道、强光和公园停车场。

Tesla 使用策略

Tesla 官方说明：Autopilot / FSD (Supervised) 需要主动驾驶员监督，不会让车辆变成完全自动驾驶。实操上，高速巡航可用；进出城、施工、山路急弯、停车场、景区道路建议人工接管。

  • 出发前更新地图和车机软件，但不要在出发当天临时升级。
  • US-26 山区和 Warm Springs 到 Madras 段保持手在方向盘上。
  • 如果晚上回程犯困，不靠 FSD 硬撑，先在 Madras / Sandy 休息。

公园与徒步规则

Smith Rock 暑期高温可接近 100°F；day-use 时间为日出前 30 分钟到日落后 30 分钟。2026 年 7 月 31 日前仍有猛禽繁殖季限制，Canyon Trail 要控制噪音和人数，drone 禁止。

  • 水至少 2 L，做 Misery Ridge 带 3 L 更稳。
  • 不要离开标记步道，碎石坡下坡很容易滑，高沙漠也可能遇到蛇。
  • 停车费当天买，Oregon State Parks day-use permit 不是国家公园年票。
