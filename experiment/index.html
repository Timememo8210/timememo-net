动了什么

  • 缓动统一：现站第一屏混用了 .2s / .3s / .4s / .5s 四五种 ease，这里全部收敛成一条 cubic-bezier(.16,.84,.26,1)——起步快、落位稳，就是「精密」的手感来源
  • 时序错峰：eyebrow → 标题 → 副标题 → CTA → 底栏，每级差 90ms，而不是一起出现
  • 字重随滚动：标题 wght 从 500 走到 580。几乎看不出来，但滚起来「有重量」
  • 晶圆微缩：滚动时缩 6%，制造景深，不抢文字
  • 接缝：加一条 170px 渐隐带，深色不再一刀切到纸面（这是现站最刺眼的一帧）
  • 强调色收敛：全页只剩冷蓝 #C4E4FF，暖桃退回去做纸面底色而不是强调色

为什么这么动

这一档的前提是不让人察觉「改版了」。现站的构图、配色、晶圆、章节全部原样。

精致感从来不是加东西加出来的，是把已有的东西对齐：同一条曲线、同一个节拍、同一个强调色。现站的问题不是「不够酷」，是这三样没对齐。

适合的场景：他不想大动，但希望别人看到时觉得「这个站做得真细」。

改哪些文件 · 工作量

base.css / full.css：统一 --transition、补 --ease token、收敛强调色、加接缝渐隐带

scene.js：保留。只把文案淡入淡出的插值曲线换掉，Three.js 晶圆不动

index.html：几乎不动，只加一个 .fade 元素

0.5 – 1 天。风险最低，可随时回滚。

附带必须做：全局 prefers-reduced-motion（现站只有 1 处）、manrope.ttf → WOFF2 子集、中文字体显式指定。

动了什么

  • 薄膜干涉的衍射环：真实晶圆表面因为膜厚差会出现那圈彩虹。用 conic-gradient + mix-blend-mode:screen 极慢反向旋转。这是现站没有、但最「硅」的一个细节
  • 晶格随章节显影：第 01 章几乎看不见，第 02 章逐渐浮出，节距更密（3.6% → 更像真的 die）
  • 第 03 章点阵拼 AI：良率点阵逐格点亮成 "AI" 字形——保留现站 177 芯片拼字的那个创意，但从 687KB 的 Three.js 换成 CSS grid
  • 光刻扫描线：一条极淡的水平光带缓慢扫过全屏
  • 标题逐字遮罩揭示 + wght 520→630 随滚动插值
  • 接缝有物理解释：抛光面把纸的颜色反射上来，220px 的反射带，不是一条渐变色

为什么这么动

现站的晶圆是「一个会反光的圆盘」。真实的晶圆有膜厚、晶格、刻痕、notch——这些细节他一眼就认得，别人看着只觉得高级。这是他这个站能有、别人抄不走的东西。

三章不再是三张图切换，而是同一块硅的三种状态：裸片 → 布上晶格 → 点亮成智能。叙事和他的职业线完全对上。

这一档是我的推荐档：识别度 100% 保留，但质感明显上了一代，而且顺手砍掉 687KB。

动了什么

  • 晶圆是唯一光源：加一层 lightcast 径向光，左边文字的明暗、文字阴影方向全部由它决定。整屏只有一个光源，这是「精密」而不是「花哨」的分界线
  • 标题被光刻曝出来：clip-path 自上而下揭示，锋线是一道会走的曝光边缘（box-shadow 发光）。这是对「光刻」最直接的视觉引用
  • 相机推进：三章不是切换，是同一个空间里 scale 7% 的推进 + 焦外 blur 景深。非当前章节是虚的
  • 光标视差：衍射环的起始角、镜面扫掠的角度、晶圆位移都跟手——硅片在你手里转
  • 底栏变仪表带：等宽、坐标、滚动百分比实时读数
  • 接缝：硅片翻面：260px 的过渡里有一道高光锋线和底部的纸张反光，深色不是「淡出」，是「翻过去」

为什么这么动

要「哇这个人很厉害」，靠的不是动得多，是每一处动都有物理依据：光从一个源出发、曝光有锋线、硅片有膜厚、焦点只有一个。半导体的人看这种克制的精密，比看粒子烟花更有感觉。

所以这一档加的全是「真实世界里会发生的事」，没有一个纯装饰的特效。推到满，但满的是密度不是噪音。

代价：光标视差 + 景深 blur 在中低端设备上要降级（已内置：触屏不启用视差，prefers-reduced-motion 下去掉 scale/blur，只留淡入淡出）。
