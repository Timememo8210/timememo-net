What this is

把今天的想法先固定下来。

这页不是最终答案，是 project memory。先把散开的语音想法变成同一个地方，之后每次有新想法都往这里加，再慢慢变成作品、课程计划、合作邮件和项目申请材料。

一句话版本

Amy wants to build creative activity boxes that use logic, psychology and art to help kids feel a little more capable, connected and understood.

为什么这个项目值得做

  • Amy 自己经历过低落和恢复，所以不是从外面“研究别人”，而是从真实体验出发。
  • 很多大人设计给孩子的心理健康材料太像说明书；孩子做给孩子，可能更真、更容易被打开。
  • 逻辑、心理学、美术三个方向不是分散爱好，可以组合成一个能展示、能测试、能扩大的 summer project。
1

先帮助自己

用这个项目整理：什么活动真的让我动起来、变平静、变有成就感。

2

再帮助别人

把有效的方法做成别人也能打开、理解、完成的小盒子。

3

最后变成组织

如果 pilot 有效果，再考虑 school club、hospital partnership 或 nonprofit。

First product map

三种 experimental boxes。

名字先用 draft。每盒都应该小、干净、安全、容易完成，避免任何会被医院拒收的材料。所有临床相关措辞都让专业人员审过再使用。

Box 01 · 一个人也能做

Solo Mastery

给低能量状态里的孩子一个小胜利。不是“振作起来”，而是一个 5-15 分钟能完成的具体动作。

logic puzzles tiny wins behavior activation
放什么推理卡、进度贴纸、低门槛手工
帮什么打破“什么都不想做”的循环
测试指标孩子是否愿意完成第一个任务

Box 02 · 不一定要硬聊

Connection Lab

帮助孩子和父母、朋友、counselor 或 group 有一点点更容易开始的连接。

question cards shared task low pressure
放什么问题卡、合作小游戏、感谢卡
帮什么从沉默到一个可以说出口的点
测试指标是否让一次对话更容易开始

Box 03 · 表达不只靠说话

Story & Art

让孩子用颜色、角色、故事和图像表达自己，不要求一开始就讲清楚。

sketchbook story prompts identity design
放什么spiral-free journal、画笔、故事模板
帮什么把乱的感觉变成能看的作品
测试指标作品完成后心情是否更可描述

第一批盒子的设计原则

  • 每一盒只解决一个小问题：开始行动、开始表达、开始连接。
  • 每个任务都要有完成感，不要像作业，不要需要很强的解释能力。
  • 材料必须干净、全新、无尖锐风险、无医疗承诺，符合医院 donation guideline。
  • 不直接收集孩子隐私；反馈只收匿名、简单、可选的信息。

要避免的坑

  • 不要写“治疗 depression”或“治愈焦虑”。
  • 不要把 Amy 的个人经历公开化，除非 Amy 明确愿意并知道后果。
  • 不要直接进入医院和病人互动，先走 Child Life / counselor / parent approval。
  • 不要一开始就做太复杂的 subscription business；先证明一个盒子真的有人愿意打开。

Learning stack

这个夏天要学什么。

课程优先选权威、可远程、可按自己的速度学的。付费 tutor 可以作为补充，但第一步先用高质量公开课程建立框架。

Psychology questions Amy wants to explore

  • People：人为什么做他们做的事？为什么有人喜欢可爱风格，有人喜欢运动，有人喜欢安静？
  • Mind reading：别人说出来的话和心里想的一样吗？微表情、身体语言能不能帮助理解？
  • Kids：小孩的 sadness、depression、happiness 是怎么发生的？什么活动能让人从低落里出来一点？
  • Design：怎样把心理学做成孩子愿意玩的东西，而不是大人写的 worksheet？

Suggested course path

  1. Yale / Coursera: The Science of Well-Being for Teens 或成人版，理解 happiness habits。
  2. Yale / Coursera 或 Open Yale: Introduction to Psychology，建立 psychology 大图谱。
  3. 选 1 门 live teen class 或 tutor：专攻 child psychology、emotion、microexpression 或 product design。
  4. 每周把学到的一个概念变成一个盒子里的 activity card。

Logic track

目标不是刷题，而是设计“能让人有成就感”的小挑战。可以从谜题、pattern、game theory、decision-making 开始。

Art / design track

学习 packaging、color psychology、illustration、story prompts。盒子本身要像一个 invitation，不像一个病历表。

STEM box model

Mark Rober / CrunchLabs 的价值是“把复杂知识变成孩子愿意打开的盒子”。可以学习它的 engagement，不必照抄它的内容。

Summer launch menu

Official courses + Wyzant mentor tracks.

先用 Coursera / Brilliant 立刻开始，再用 Wyzant 找 tutor 把 Harvard-level topics 拆成适合 8 年级的 syllabus。重点不是“神秘读心”，而是注意偏差、行为奖励、盲点判断、逻辑结构和动机设计。

Official University Platforms Amy can start now

These are the broad, on-demand foundations. They are useful for learning and portfolio evidence, but the project should describe them accurately as online courses or guided platforms, not as direct enrollment in the universities.

Yale Coursera Paul Bloom psych foundation

Introduction to Psychology

Search: “Introduction to Psychology Yale.” Broad overview of behavior, memory, development, emotion, social psychology, clinical psychology, and happiness.

Project use: gives Amy the vocabulary to explain why logic, habit, feeling, and social connection belong in the same box project.

Duke Coursera Think Again informal logic

Think Again: How to Reason and Argue

Search: “Think Again Duke.” This is the Coursera / Duke logic and critical-thinking sequence: claims, reasons, assumptions, validity, and fallacies.

Project use: helps convert “craft instructions” into clear if/then steps and helps Amy spot when a workbook prompt is confusing or logically overloaded.

Brilliant Logic CS pathways interactive

Logic & Computational Thinking Pathways

Search inside Brilliant for “Logic” and “Computer Science.” Use visual puzzles, algorithms, conditionals, and structured problem solving as daily practice.

Project use: trains the “20 x 20 x 20” kit rule: 20 minutes, 20 pieces or fewer, first step understandable in 20 seconds.

Coursera Madecraft 4 hours bias toolkit

Overcoming Cognitive Bias

学 confirmation bias、hindsight bias、attribution bias、availability bias、inattentional blindness、anchoring 和 blind spot bias。它适合快速建立“脑子会怎样自动走偏”的 vocabulary。

Box use: 给 Logic Kit 做“what did I miss?” 小卡片，让孩子练习把注意力从单一负面线索移开，去找事实、例外和下一步。

Guardrail: 不能说 depression “本质上就是” inattentional blindness。更准确：低落状态可能伴随注意偏差和负面过滤，但 depression 是多因素问题。

Yale Coursera Alan Kazdin behavior shaping

Everyday Parenting: The ABCs of Child Rearing

表面是 parenting，核心是行为改变工具：antecedents、positive reinforcement、tone、phrasing、practice、shaping，以及什么时候需要专业帮助。

Box use: 设计 instruction booklet，让第一个动作非常小、非常清楚，并且完成后马上有可见 reward，不靠大人说教。

Guardrail: 这不是让 Amy “治疗别人”或当 ABA practitioner；它是学习如何把说明、反馈和环境设计得更友善。

Harvard Online Mahzarin Banaji leaders / teams hidden bias

Make Better Decisions: The Psychology of Blind Spots

这门课研究 hidden bias 和 intuitive decision-making：我们怎样在不自觉中形成判断，怎样误读他人，怎样让 decision process 减少盲点。

Box use: 给 Connection Lab 做 parent/teen “assumption check” 卡片：我以为你在想什么？证据是什么？还有没有另一个解释？

Guardrail: 它更偏成人 leadership training，可能贵；对 Amy 来说可以让 tutor 提炼核心概念，不一定要马上上完整课。

Wesleyan Coursera Alexis May motivation loops

Creating Behavioral Change

覆盖 classical / operant conditioning、motivational interviewing、CBT 基础、behavioral activation、SMART goals 和 relapse prevention。它最贴近“怎样从卡住到开始动”。

Box use: 给 Solo Mastery 做 20 x 20 x 20 craft constraints：20 分钟内、20 个以内零件、20 秒内看懂第一步，让行动门槛低到可以开始。

Guardrail: Coursera 页面明确说这门课不会训练你给别人实施心理干预；项目只能做 supportive design，不能做 therapy claim。

Best starting order

  1. Wesleyan Creating Behavioral Change：先学 action loop 和 behavioral activation。
  2. Yale Everyday Parenting：再学 reward、phrasing、step design。
  3. Overcoming Cognitive Bias：补齐 attention / judgment vocabulary。
  4. Harvard Blind Spots：作为 advanced framework，让 tutor 帮忙拆概念。

Wyzant message draft

I want to study cognitive bias, blind spots, behavioral modification, motivation, and behavioral activation in a research-safe way. My goal is not to practice therapy. I want to design supportive craft/activity kits for teens that encourage tiny actions, reflection, and connection. Can you help me turn ideas from Harvard's Psychology of Blind Spots, Yale's Everyday Parenting, Wesleyan's Creating Behavioral Change, and cognitive-bias frameworks into age-appropriate activity-card experiments?

Wyzant mentor tracks using Harvard course names as syllabus targets

Track 1 Neuroscience Clinical psychology social connection

Mind & Social Environment Specialist

Wyzant search terms: “Neuroscience,” “Clinical Psychology,” “Adolescent Psychology,” “Social Psychology.” Harvard target topics: PSYC S-1609 Neuroscience of Learning and youth social-connection frameworks.

Safe message: “Hi, I am an 8th grader building a student-led supportive art/activity kit project around teen well-being. I am not practicing therapy or conducting clinical research. Can you teach me neuroplasticity, learning science, and adolescent social connection in a way I can turn into safe reflection/activity cards?”

Track 2 Symbolic logic Formal logic systems design

Logic & Systems Specialist

Wyzant search terms: “Symbolic Logic,” “Formal Logic,” “Mathematical Logic,” “Philosophy.” Harvard target topic: PHIL S-12 Deductive Logic.

Safe message: “Hi, I want help turning real-world craft instructions, like ribbon folding or box assembly, into clear logical algorithms and error-proof checklists for activity kits. Can you teach me deductive logic and structured proof-style thinking at a middle-school-friendly pace?”

Track 3 Behavioral economics Statistics survey design

Choice & Data Specialist

Wyzant search terms: “Behavioral Economics,” “Statistics,” “Survey Design,” “Neuroeconomics.” Harvard target topic: ECON S-1915 Neuroscience and Economic Decision-Making.

Safe message: “Hi, I want to learn cognitive biases like present bias and design a simple anonymous QR-code feedback form for a summer activity-kit prototype. I am not collecting clinical data; I only need product feedback such as clarity, energy, and willingness to continue.”

Tutor filter: pick someone who can teach advanced ideas to a middle-school student, will stay within educational coaching, and is comfortable with parent involvement. Do not ask a tutor to diagnose, treat, supervise therapy, or run a medical study.

Mandarin project blueprint

行为激活设计实验。

这是给中文沟通、制造打样、导师协作和国际展示使用的专业版表述。项目可以借鉴心理学、逻辑学和行为选择理论，但必须写清楚：这是非临床、学生主导的支持性活动礼盒设计探索，不是治疗方案、医疗研究或临床试验。

项目名称

行为激活设计实验
The Behavioral Activation Design Experiment

supportive activity kits logic structure tactile art anonymous feedback

核心使命

将行为激活的基本思想——通过小而清楚、有结构、有完成感的活动，帮助人从低能量和反复消极思绪中迈出一步——转化为高质感、可打样、可反馈的个人手作支持礼盒。

安全边界：页面和对外材料不应声称“治疗青少年抑郁症”。更准确的说法是：支持青少年情绪健康、提升行动感、表达感和连接感。

心理学框架

参考行为激活、青少年社会连接、学习科学和注意偏差。核心问题是：什么样的小活动更容易让孩子开始行动、继续完成，并愿意表达自己的感受？

逻辑学框架

参考 Harvard PHIL S-12 一类的演绎逻辑和结构化推理，把手作步骤设计成清楚、可验证、低错误率的算法。

选择与设计框架

参考 behavioral economics、choice architecture 和 cognitive bias，研究材料、顺序、反馈和社交环境如何影响孩子是否愿意继续。

20 x 20 x 20 规则：20 分钟内能完成一个阶段；20 个以内核心零件；20 秒内看懂第一步。目标不是强迫进入“心流”，而是降低开始门槛，让完成感自然出现。

礼盒 1 · 安全地带

独立掌控礼盒

以真丝丝带玫瑰、植物花艺和精细折叠为主，适合孩子在安静、熟悉、可控的空间里独立完成。

设计目标安全感、掌控感、完成感
适用情境低能量、想独处、需要安静任务
反馈问题第一步是否容易开始？完成后是否更平静？

礼盒 2 · 家庭之桥

互动指尖解压礼盒

以磁吸木质结构、几何拼图或链环结构为主，设计成低压力双人协作模型。

设计目标共同专注、低压力对话、关系修复
适用情境亲子沟通卡住，但仍愿意一起做事
反馈问题合作是否降低尴尬？对话卡是否自然？

礼盒 3 · 社交网络破局

协作网格礼盒

以模块化 3D 几何马赛克或纸艺瓷砖为主，每个人独立完成一块，再在学校、club 或经批准的社区活动中拼成集体作品。

设计目标独立贡献、社区连接、可见归属感
适用情境想参与集体，但不想被迫社交
反馈问题是否更愿意带作品加入集体墙？

反馈系统：设计验证，不是临床试验

  • 每个礼盒附一张高质感反馈卡，用二维码进入 1-2 分钟匿名问卷。
  • 测量自我报告的即时感受变化，例如更清楚、更平静、更愿意继续，而不是生物指标或医疗结果。
  • 记录哪种环境更匹配：独立完成、亲子协作、社区拼接。
  • 不收姓名、诊断、病史或敏感健康信息；未成年人反馈需要 parent / school / partner approval。

我正在做一个面向青少年情绪健康的学生主导支持性活动礼盒项目，不是临床治疗或医疗研究。我希望学习哈佛水平的神经科学、逻辑学和行为选择理论，把它们转化成安全、适龄、可执行的手作说明书、对话卡和匿名反馈问卷。您能否帮助我把高级概念拆成适合 8 年级学生理解和设计的课程计划？

Partner map

先从安全、可信的合作开始。

医院是最终方向之一，但第一个 pilot 更适合从家庭、school counselor、老师或小型 youth group 开始。医院 donation 需要严格遵守物品、隐私、感染控制和访问规则。

School route

  • 找 counselor / Ben 先聊项目定位。
  • 可做成 wellness club、student showcase 或 advisory activity。
  • 优点：反馈快，风险低，Amy 不需要一开始公开太多私人经历。

Hospital route

  • 先联系 Child Life / donation office，不直接联系病人。
  • 只送全新、可清洁、符合 wish list 的活动材料。
  • 如果未来要带活动，需要医院 staff 审核和现场安排。

Nonprofit route

  • 短期可以先做 family project 或 fiscal sponsor，不急着注册。
  • 如果注册 nonprofit，Oregon Secretary of State、Oregon DOJ、IRS EIN / 501(c)(3) 都要处理。
  • 未成年人和银行、税务、签字责任相关问题，需要父母或专业人士确认。

最聪明的起点：先做 3 个 prototype，找 3-5 个可信的人试用，拿到反馈，再决定是走 school、hospital donation，还是 nonprofit。
