# AI Material — static color study

Preview: https://timememo.net/prototypes/ai-material/colors/

Four proposed palettes, plus the current silver baseline. The owner requested a static comparison because the existing motion was already approved. This page does not change the motion demo or production homepage design.

- A: Ink / Ember — recommended warmer professional direction.
- B: Petrol / Glacier — stronger cool technology direction.
- C: Porcelain / Cobalt — light editorial direction, limited blue accents.
- D: Plum / Apricot — more expressive personal direction.
- 0: Current silver — comparison baseline.

The preview uses responsive HTML text and local transparent WebP renders of the existing Three.js wafer geometry. The public page has no WebGL loop, CSS animations, transitions, autoplay, or third-party requests. Utility icons remain neutral SVG strokes. Palette and language choices are encoded in the URL (`?palette=glacier&lang=en`); they do not overwrite any existing homepage language preference.

The ending proposal rearranges the original 177 chip instances into A (108 chips) and I (69 chips). It is a static composition proposal, not an implemented animation. The preceding two-panel layout is shown alongside it to explain the change in meaning. Both assets were rendered from the existing chip geometry/material, not generated from edited screenshots.

Rendered QA covered five palettes × two languages × four viewports (320, 390, 768, 1440), immediate selection, contact-sheet navigation, shareable URLs, name wrapping, missing assets, document overflow, and absence of animations. Evidence and asset-generation scripts are in the workspace output folder `outputs/timememo-color-study-20261004/` and are not part of the published site.
