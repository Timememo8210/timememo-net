默认模型：Gemini 3.1 Flash Lite

云端服务已能读取图片与 PDF。模型结果是草稿：核对原件、修改字段、明确确认后才保存。试用需独立访问码。

记录和原件仍保存在此浏览器，尚未实现共享客户账户与房屋云数据库。

发现、修正与限制

  • 修复了实际遇到的 Gemini 400 错误：向提供商发送兼容的结构规范，返回后仍执行完整字段与长度校验。
  • 报价单不会建立实际施工人、实际服务日期或付款事实。报价总额仍明确属于报价单。
  • 早期 API 测试中，严重模糊和风景照片没有生成维修字段。餐厅小票在修订版 API 测试及已部署云端测试中均被归为无关文件。这些 API 结果与下方记录的网页操作验收分别列示。
  • 一张不完整电工单仍将公司名缩短为 SOUTHMERE SPARK，需要用户对照原件补全。这是仍存在的模型限制。
  • 当前最小格式区分总额与付款状态；税额、已付订金、剩余应付尚无独立结构化字段。
  • 前端 85 项、接口 12 项自动检查通过。真实 API 调用与下方浏览器截图属于另外两类验收证据。
