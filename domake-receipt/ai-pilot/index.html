Findings and limits

  • Fixed an actual Gemini 400 error: the provider receives a compatible structural schema; the service still validates the full bounds after generation.
  • Quotes no longer establish an actual worker, completed service date or payment. Quote totals stay explicitly attached to an estimate.
  • Early API tests of unreadable blur and landscape controls generated no maintenance details. The restaurant receipt was classified as unrelated in both the revised API run and the deployed cloud run. These API observations are separate from the browser checks documented below.
  • One incomplete electrical slip still shortened the company name to SOUTHMERE SPARK. Users can correct it; this is a remaining model limitation.
  • The minimal schema separates total and payment status; VAT, paid deposit and outstanding balance do not yet have dedicated structured fields.
  • 85 frontend and 12 service automated checks passed. Live API calls and the browser screenshots below are separate evidence.
