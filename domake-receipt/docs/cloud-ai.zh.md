## 本地 OCR 与云端模型的差别

现有网页使用浏览器里的 Tesseract OCR 加规则提取：它先读出文字，再按日期、金额等模式抓字段，不需要用户 Mac 运行一个本地大模型服务器。困难主要在语义：区分客户和实际工人、办公室与施工地址、报价与实际付款、账单日期与服务日期。多模态大模型直接阅读文档并整理这些关系，但依然可能误读或补全，因此仍要保留原件、缺失字段和人工确认。

云端 API 的方案不依赖网站作者的 Mac 开机；用户浏览器上传到云端接口，由接口调用模型。API Key 不放在网页里。

## 已实现的代码

- 英文默认、中文切换；识别方式可选云端 AI、本地 OCR、手工录入。
- 独立试用访问码、文件类型/大小检查、超时和可恢复错误。
- 固定输出 JSON、缺失值 null、逐字段证据、公司与实际服务人分开。
- 上传识别 → 用户查看/修改 → 勾选确认 → 保存原件与记录。没有确认不进入已确认记录。
- 保存后的原件可以重新识别，仍需再次确认；不会由模型直接决定用户或房屋归属。
