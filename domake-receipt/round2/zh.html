01 / OUTPUT CONTRACT · SCHEMA 1.2

确认界面和最终保存的格式

用户看到的是一张带字段名称的核对表，编辑时可对照原件。确认保存必须有归属房屋和工作摘要；其余事实未知可以留空。下表示例用于说明规则；下载的 JSON 则是从管理端实际读回的记录。

02 / REVIEW BEFORE SAVE

上传之后，用户一步步看到什么

1. 添加单据

选择上传身份、房屋，再上传一份 PDF 或图片。

2. 查看结果

能读到的图片弹出核对摘要；不完整、不相关或无文字各有提示。PDF 进入手工模式。

3. 修改信息

对照原件核对每项数据；缺失可保留未知，业务字段均可编辑。

4. 确认归档

最终表格也包含已填的补充信息。勾选核对声明才可确认保存；保存后仍能再编辑。
