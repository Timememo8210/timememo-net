02 / REVIEW BEFORE SAVE

What happens after upload

1. Add document

Choose uploader context and a property, then upload one PDF or image.

2. Inspect result

A readable image opens a review summary. Partial or unrelated content gets a specific recovery message. PDF stays manual.

3. Edit details

Review every field against the original. Missing data stays unknown. All business fields can be edited.

4. Confirm and save

The final table includes optional details you filled. Tick the review checkbox, then save. Saved records remain editable.

06 / EVIDENCE & NEXT ITERATION

What passed, what still needs work

LayerEvidence and conclusion
Browser workflow9 confirmed records saved and reopened; 216 final form values match. 80 blanks remain null; 14 unknown enums remain unknown. All nine file SHA256 values match the uploaded fixtures. Original previews were opened; stored-blob byte equality is covered by a separate controlled storage test, not a second independent browser byte download.
Recognition qualityAll ten PNGs: 5 partial, 4 uncertain, 1 unrelated; zero fully extracted. For 72 primary fields across nine home documents: 15 correct nonempty, 9 correctly blank, 47 missing stated facts and 1 incomplete address. Company names and full work summaries often need human entry.
Automated checks54 repository tests passed, plus 11 context/persistence checks and a management loading-failure probe. These include controlled failure tests, not observations of a live service outage.
ExportThe actual UI CSV preview was read and made available above. Select all works. Browser file-download completion was not verified; the report provides a static CSV and full saved JSON.
Not yet measuredGemini model accuracy/cost/latency; automated PDFs and multi-document files; physical-phone capture; Chrome/Safari compatibility; real multi-user authorization, cloud backups and production load.

Bugs addressed in this iteration

  • Explicit UK dates and £ totals; reject conflicting totals, OCR garbage and impossible dates.
  • Keep customers, preparers and proposed workers out of actual-worker fields.
  • Changing a property name clears and refreshes its old association.
  • Slow original loads cannot replace another record’s attachment; data-load failures clear previous results and disable export.
  • Filled optional details and line items appear in final confirmation. Mobile navigation no longer overlaps.
  • New uploads clear old success notices; CSV contents are visible and selectable.

Decide Pro/owner approval rights, quote/invoice deduplication, payment/VAT fields and the minimum acceptable completion rate together.
