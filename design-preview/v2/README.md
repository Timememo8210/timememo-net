# Homepage concepts, round two

Four original, independent compositions at `?style=bento`, `?style=gallery`,
`?style=desktop`, and `?style=journal`. They share the existing 16-project
catalog in `../assets/directory.js` and the user's original `/avatar.jpg`.

## User requirements

- The homepage and design previews open without a password.
- Keep the portrait's original skin tone and colors in every theme and state.
  Never apply grayscale, tint, desaturation, color blending, or color-changing
  hover effects. A background-only image edit is allowed if needed, but must
  preserve the person and their colors. These concepts use the unchanged image.
- Concepts must differ in layout, information structure, and interaction.
- The formal homepage stays as it is until the user chooses a concept.

## Structural references

These are references for interaction and layout, not copied template source.
No paid template was purchased or imported.

- E / Bento: https://www.framer.com/marketplace/templates/bentory/
- F / Gallery: https://www.framer.com/marketplace/templates/panoramic/
- G / Desktop: https://www.framer.com/marketplace/templates/desktop-os/
- H / Journal: https://www.framer.com/marketplace/templates/the-voss-report/

Static HTML/CSS/JavaScript served through the existing GitHub Pages site.
The gallery supports touch scrolling, arrow buttons, and arrow keys while the
track is focused. Desktop window dragging is disabled on small screens, where
windows use a readable stacked layout. Dialogs support Escape and return focus
to the opener. Animation honors reduced-motion preferences.
